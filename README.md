### ✦ About Me

Hey, I'm **Arka**. I'm a Linux desktop developer and systems enthusiast focused on building fast, beautiful software for **Arch Linux** and **Wayland**.

- 🔭 Currently building [**Aura Store**](https://github.com/Desplicableme/aura-store) — a modern, minimal macOS-inspired App Store designed for Hyprland.
- ⚡ Deeply interested in Wayland protocols, GTK4/Libadwaita desktop engineering, and containerized sandboxes.
- 🐧 Daily driver: Arch Linux + Hyprland + Neovim.
