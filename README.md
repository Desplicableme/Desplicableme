### 🚀 About Me

I am a passionate **Linux Desktop & Systems Engineer** dedicated to building polished, high-performance software for the modern Linux ecosystem. My primary focus lies in bridging the gap between deep operating system capabilities and fluid, Apple-grade user interfaces on **Arch Linux** and **Wayland**.

- 🔭 **Current Flagship**: Designing and engineering [**Aura Store**](https://github.com/Desplicableme/aura-store) — a minimal, modern macOS-inspired App Store purpose-built for Hyprland.
- ⚡ **Core Focus**: High-performance GUI applications (GTK4 + Libadwaita), Wayland IPC, container sandboxing (Docker OCI), and package distribution (Pacman, AUR, Snap).
- 🛠️ **Workflow**: Driven by Arch Linux, custom Hyprland compositing, Neovim, and minimalist UNIX tooling.
